# media

Photos and other media from [vens](https://github.com/venslabs/vens) talks and
events. The originals live here so the vens repo stays small; the docs site
only carries thumbnails that link back to these files.

## Rights

Every photo belongs to its author. Nothing in this repo is under the vens
Apache-2.0 licence, or under any open licence: we use the files with the
author's permission. Ask the author before reusing one anywhere else.

## Credit

Wherever a photo is shown, the credit goes on the page itself, not only in the
alt text. Each event folder has a `credits.yml` with the exact line to use.

## What goes in

- Stage shots, or frames where the audience is incidental.
- Nothing that singles out an identifiable attendee.

## Adding photos

Through a pull request only, `main` takes no direct pushes. One folder per
event under `events/`, named `YYYY-MM-DD-event-name`, with a `credits.yml`
next to the photos (event, date, photographer, credit line, rights).
